<h2 align="center"> 🧩 1. What is Financial Accounting?</h2>

Financial Accounting is the **systematic recording, summarizing, and reporting** of business transactions.

### 📘 *Core Objectives*

* ✔️ Record transactions
* ✔️ Maintain financial accuracy
* ✔️ Determine profit/loss
* ✔️ Show financial position
* ✔️ Comply with legal requirements

---

<h2 align="center">  🏛️ 2. Core Accounting Concepts</h2>

| Concept               | Meaning                                 | Emoji    |
| --------------------- | --------------------------------------- | -------- |
| **Business Entity**   | Owner ≠ Business                        | 🧑‍💼➗🏢 |
| **Money Measurement** | Only money-based events are recorded    | 💰📘     |
| **Dual Aspect**       | Every transaction has debit & credit    | 🔄       |
| **Going Concern**     | Business continues long-term            | 🔁🏭     |
| **Accrual**           | Record when incurred, not when received | 🗓️      |

---

<h2 align="center">  🔢 3. Accounting Equation</h2>

```
🟦 Assets = 🟩 Liabilities + 🟧 Capital
```

Example:
If business buys machinery worth ₹50,000 (on loan):

```
Assets ↑ 50,000 = Liabilities ↑ 50,000 + Capital
```

---

<h2 align="center">  📚 4. Accounting Cycle</h2>

```
[Transaction] → [Journal] → [Ledger] → [Trial Balance] → 
[Adjustments] → [Final Accounts]
```

---

<h2 align="center">  🧾 5. Golden Rules of Accounting</h2>

(VERY Important for Tally Entry)

| Account Type | Rule                                        | Emoji    |
| ------------ | ------------------------------------------- | -------- |
| **Personal** | Debit the receiver, Credit the giver        | 🧑‍🤝‍🧑 |
| **Real**     | Debit what comes in, Credit what goes out   | 🏦       |
| **Nominal**  | Debit expenses/losses, Credit incomes/gains | 📈📉     |

<h2 align="center">  📊 10. Example Transactions → Journal → Tally Entry</h2>

### **Transaction 1:**

Started business with ₹1,00,000 capital.

| Journal        | Debit    | Credit   |
| -------------- | -------- | -------- |
| Cash A/c       | 1,00,000 |          |
| To Capital A/c |          | 1,00,000 |

**Tally Voucher:**

> Receipt Voucher (F6) → Cash Dr → Capital Cr

---

### **Transaction 2:**

Bought furniture for ₹20,000 (cash).

| Journal       | Debit  | Credit |
| ------------- | ------ | ------ |
| Furniture A/c | 20,000 |        |
| To Cash A/c   |        | 20,000 |

**Tally Voucher:**

> Payment Voucher (F5) → Furniture Dr → Cash Cr

---

### **Transaction 3:**

Sold goods for ₹15,000 + GST.

| Journal           | Debit  | Credit |
| ----------------- | ------ | ------ |
| Cash/Customer A/c | 15,000 |        |
| To Sales A/c      |        | 15,000 |

**Tally Voucher:**

> Sales Voucher (F8)
